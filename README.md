**Gobble Dash — The Great Turkey Escape.** A 2D canvas side-scrolling escape runner: a turkey flees Thanksgiving dinner, chased by a pitchfork farmer through the farmyard, the barn and the kitchen, dodging fences, hay bales, low branches, rolling pumpkins, falling and swinging carving knives and oven flames. Jump, double-jump and turbo-dash, duck under hazards, grab corn (it slows the farmer down), power-ups and golden corn, build score combos, and reach FREEDOM 3000 m down the road before the farmer catches you. Title screen, HUD (score / distance / lives / combo / zone progress), caught and escaped end screens with restart, synthesized sound effects and music, no assets and no network — everything is vector art and WebAudio, so it plays fully offline.

## Run it

```sh
python3 -m http.server 8901 --directory game
```

Then open http://localhost:8901/ in a desktop browser. **SPACE / CLICK** jump (twice = double jump), **SHIFT** turbo dash (smashes fences and hay, phases through danger), **↓ / S** duck under branches and swinging knives, **P** pause, **M** mute.
